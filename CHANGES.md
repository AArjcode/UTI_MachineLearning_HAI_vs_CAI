# Repository maintenance and provenance

This repository accompanies the article published in the *Journal of Hospital
Infection* (2025;162:263–271, DOI: 10.1016/j.jhin.2025.04.024).

The October 2026 maintenance update improves the usability of the publicly
archived scripts without changing their model definitions, preprocessing,
train/test splitting, or random seeds. The earlier publicly posted source
remains accessible through the Git commit history. A tag of the pre-maintenance
commit, if created, identifies that **public repository snapshot**; it does
not independently establish the exact code or software environment used to
produce the published results.

## October 2026

- **All five scripts:** replaced incomplete, machine-specific Excel file paths
  with a command-line argument (`python Src/<script>.py data.xlsx`).
- **`RF_HAI.py` and `XGBoost.py`:** corrected the ROC-curve legend to compute
  AUC from predicted probabilities rather than referencing a function-local
  variable, avoiding an end-of-script `NameError`.
- **`LR_HAI.py`:** exponentiated the 95% confidence-limit bounds so that the
  exported confidence intervals and odds ratios use the same scale. Model
  coefficients, odds ratios, selected features, and predictions are unchanged.
- **Documentation and demonstration:** added `README.md` improvements,
  `CITATION.cff`, `requirements.txt`, and `example/` with wholly synthetic
  records generated by `example/make_synthetic_data.py`.

The synthetic example demonstrates the input format and execution of the
scripts; it does not reproduce or validate published clinical performance.
